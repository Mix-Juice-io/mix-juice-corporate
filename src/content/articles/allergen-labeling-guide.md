食品のアレルギー表示（アレルゲン表示）の対象は、2026年4月から**29品目**です。表示が義務の「特定原材料」が9品目、表示が推奨される「特定原材料に準ずるもの」が20品目です。以前よく見かけた「28品目」「8品目」は、2026年3月までの数え方です。

この記事では、食品を作って売る事業者（ネットショップを含む）向けに、対象品目と改正の経緯、個別表示・一括表示の書き方、コピーして使える表示のテンプレート、間違えやすい表記、商品ページでの載せ方を、消費者庁の資料をもとに説明します。

| 確認したいこと | 結論 |
|---|---|
| 表示義務の対象 | 特定原材料9品目を含む、容器包装された加工食品 |
| 推奨される品目 | 特定原材料に準ずるもの20品目（義務とあわせて29品目） |
| 「28品目」「8品目」 | 2026年3月までの数え方。カシューナッツが義務に移り、ピスタチオが推奨に加わった |
| 基本的な書き方 | 原則は個別表示。個別表示がなじまない場合などは一括表示も可能 |
| EC商品ページ | 食品表示基準の直接の適用対象ではないが、実物ラベルとの食い違いを防ぐ情報提供が重要 |

> 本記事は一般的な情報提供を目的としています。表示例は条件を示した例示であり、そのまま使用することで個別の商品の適合性を保証するものではありません。実際の表示は、原材料の規格書や製造工程を確認し、最新の法令・行政資料に基づいて判断してください。

## アレルギー表示の義務とEC商品ページの違い

消費者庁は、特定原材料を含む容器包装された加工食品に、アレルゲンを含む旨の表示を義務付けています。栄養成分表示と違い、事業の規模による省略はありません。作った店で売る場合も、包装して売る商品には表示が必要です。

一方、ECの商品ページへの掲載には食品表示基準が直接適用されません。ただし、消費者庁のEC向けガイドブックは、容器包装の表示事項をできる限り食品表示基準に準じて掲載し、実際に届く商品とのギャップを防ぐよう求めています。購入前に商品を選ぶための重要な情報として、正確で見つけやすい掲載が必要です。

ばら売りや量り売りなど、容器包装に入れずに売る食品は表示義務の対象外ですが、消費者庁のハンドブックは、義務がかからない場合でも、メニューやウェブサイトに特定原材料等を表示するなどの取り組みを求めています。栄養成分表示など、ほかの表示が自社に必要かどうかは、[栄養成分表示の要否チェック](/tools/nutrition-labeling-check/)で確認できます。

## アレルギー表示の対象は29品目

食品表示基準で表示を義務付けている**特定原材料**が9品目、消費者庁の通知で表示を推奨している**特定原材料に準ずるもの**が20品目です。消費者庁のハンドブックは、この2つをあわせて「特定原材料等」と呼び、「特定原材料に準ずるものを含む29品目」と書いています。「特定アレルゲン」という言い方を見かけることもありますが、食品表示基準や消費者庁の資料での名称は「特定原材料」です。

### 特定原材料9品目（表示の義務）

| 品目 | 主な食品例 |
|---|---|
| えび | えびせんべい、えびフライなど |
| カシューナッツ | ミックスナッツ、焼き菓子など |
| かに | かにカマボコ、かに缶など |
| くるみ | くるみパン、くるみ菓子など |
| 小麦 | パン、うどん、ソースなど |
| そば | そば麺、そばがきなど |
| 卵 | マヨネーズ、卵焼きなど |
| 乳 | チーズ、バター、ヨーグルトなど |
| 落花生（ピーナッツ） | ピーナッツバター、ピーナッツ菓子など |

2026年4月にカシューナッツが加わり、9品目になりました。2028年3月31日までに製造・加工・輸入される加工食品は、改正前の例によることができる経過措置があります（令和8年内閣府令第34号附則第2条）。ただし消費者庁は、可能な限り速やかに表示するよう求めています。

※くるみは2023年3月に加わりました。経過措置は2025年3月31日で終わっています。

### 特定原材料に準ずるもの20品目（表示の推奨）

以下の20品目は、義務ではありませんが、表示が推奨されています。

アーモンド、あわび、いか、いくら、オレンジ、キウイフルーツ、牛肉、ごま、さけ、さば、大豆、鶏肉、バナナ、ピスタチオ、豚肉、マカダミアナッツ、もも、やまいも、りんご、ゼラチン

2026年4月にピスタチオが加わりました。消費者庁は、カシューナッツとの交差反応性も踏まえ、可能な限り速やかに表示するよう求めています。

推奨品目は表示しなくても違反ではありません。ただ、書いていないだけでは「使っていない」のか「使っているが書いていない」のかが分かりません。そのため消費者庁のハンドブックは、義務の9品目だけを対象にしているのか、29品目を対象にしているのかを、一括表示の枠の近くに書くことが望ましいとしています（書き方は[テンプレート](#コピーして使える表示のテンプレート)を参照）。

## 「28品目」「8品目」は2026年3月までの数え方

「アレルギー表示 28品目」で調べると、今も「義務8品目＋推奨20品目＝28品目」の一覧がよく出てきます。これは2026年3月までの数え方です。2026年4月1日に、推奨だったカシューナッツが義務（特定原材料）に移り、推奨にピスタチオが加わりました。

| | 2023年3月〜2026年3月 | 2026年4月から |
|---|---|---|
| 義務（特定原材料） | 8品目 | 9品目（カシューナッツが加わる） |
| 推奨（特定原材料に準ずるもの） | 20品目（カシューナッツを含む） | 20品目（ピスタチオが加わる） |
| 合計 | **28品目** | **29品目** |

近年の変更は次のとおりです。

- 2019年9月：推奨にアーモンドを追加
- 2023年3月：義務にくるみを追加
- 2024年3月：推奨にマカダミアナッツを追加し、まつたけを削除
- 2026年4月：カシューナッツを義務に移し、推奨にピスタチオを追加

古い一覧表や原材料の管理表を使っている場合は、次の3点を見直します。

- カシューナッツを義務（特定原材料）の欄へ移す
- 推奨の欄にピスタチオを加える
- まつたけが残っていれば外し、マカダミアナッツを加える

カシューナッツの経過措置の間は、改正前の数え方で表示した商品も出回ります。ハンドブックは、表示がどの時点の品目を対象にしているか分かりにくい場合に、いつ時点の内閣府令や通知に基づく表示かが分かるように書くこともできるとしています。

## アレルギー表示の書き方と例

### 個別表示（原則）

個別表示は、原材料名や添加物の物質名の直後に、含まれる特定原材料等を括弧書きで示す方法です。どの原材料に何のアレルゲンが含まれるかを確認しやすくなります。原材料には「（〇〇を含む）」、添加物には「（〇〇由来）」と書くのが原則です。

以下は、小麦粉・卵・バターを使う焼き菓子を想定した例示です。

```text
原材料名：小麦粉（国内製造）、砂糖、卵、バター（乳成分を含む）、食塩
```

同じ特定原材料等が2つ以上の原材料に含まれる場合は、どれか1つに書けば、ほかは省略できます。ただし、しょうゆの小麦・大豆、みその大豆のように、アレルギーのある人でも食べられるといわれる原材料にだけ書いて、ほかを省略するのは避け、それ以外の原材料に書くことが望ましいとされています。ハンドブックには、先に書いた「乳糖」で乳を示したために、後ろの植物油脂に含まれる乳の表示を省いた事例が、注意すべき事例として載っています。

### 一括表示（例外）

一括表示は、原材料名の欄の最後に、含まれるすべての特定原材料等を「（一部に〇〇・〇〇を含む）」とまとめて書く方法です。添加物がある場合は、添加物の後ろ（欄の最後）に書きます。原材料と添加物で欄を分ける場合は、それぞれの欄の最後に書きます。

個別表示で表示できない場合や、表示できる面積の都合などで個別表示がなじまない場合に使えます。消費者庁のハンドブックは、次のような場合を例に挙げています。

- 表示できる面積に限りがあり、一括表示でないと表示が難しい場合
- 原材料に使った添加物に特定原材料等が含まれるが、キャリーオーバーに当たり、その添加物が表示されない場合
- 個包装していない食品を詰め合わせ、特定原材料等を含む食品と含まない食品が触れる可能性が高い場合

個別表示と一括表示を組み合わせることはできません。上記と同じ原材料構成を一括表示にした場合の例示は次のとおりです。

```text
原材料名：小麦粉（国内製造）、砂糖、卵、バター、食塩、（一部に小麦・卵・乳成分を含む）
```

一括表示では、「小麦粉」「全粉乳」などの代替表記・拡大表記で書かれた原材料を含め、すべての特定原材料等を記載します。実際の商品では、ここで示した品目だけを写すのではなく、原材料・添加物と製造工程を確認して表示を作成してください。

### 乳成分は名称だけで判断しない

「乳」については「乳成分を含む」と表示します。例えば、乳を含むチョコレートを原材料に使う場合の個別表示は「チョコレート（乳成分を含む）」です。

バター、チーズなどは代替表記に当たり、含む旨の表示を省略できますが、消費者庁のハンドブックは、可能な限り「乳成分を含む」と表示することが望ましいとしています。原材料名に「乳」の文字がないことだけで、表示不要と判断しないようにします。

### 間違えやすい表記

- **卵白・卵黄**：「卵」の拡大表記に当たらないため、「卵白（卵を含む）」「卵黄（卵を含む）」のように書きます。
- **乳化剤・乳酸・乳酸菌**：名前に「乳」が入っていても、「乳」の拡大表記には当たりません。
- **添加物の「乳」**：原材料では「乳成分を含む」ですが、添加物では「カゼインナトリウム（乳由来）」のように「乳由来」と書きます。
- **加工助剤・キャリーオーバー**：添加物としての表示が要らない場合でも、特定原材料等の表示は必要です。
- **代替表記**：使えるのは決められた表記だけです（例：卵→「玉子」「たまご」、小麦→「こむぎ」「コムギ」）。「穀類」「肉類」のようにまとめた書き方は認められていません。

### 複合原材料は規格書で内訳を確認する

パン粉、しょうゆ、ソース、マーガリンなどの複合原材料には、名称からだけでは分からない特定原材料等が含まれることがあります。仕入れ先の規格書などで内訳を確認し、必要に応じて二次原料・三次原料までさかのぼって確認します。

例えば、使用するマーガリンに乳と大豆が含まれる場合の個別表示は、次のように示せます。

```text
原材料名：小麦粉（国内製造）、砂糖、マーガリン（乳成分・大豆を含む）、食塩
```

同じ「マーガリン」という名称でも内訳が同じとは限りません。商品名だけで例示を転用せず、仕入れ先・製造委託先から入手した最新の情報を使います。

### 製造ラインの共有（コンタミネーション）への対応

意図して使用する原材料の表示と、製造工程での意図しない混入への対応は分けて考えます。製造ラインを共有する場合は、洗浄、製造順の考慮、専用器具の使用などで混入を防ぐことが原則です。

徹底した防止策を講じても、製造ロットによっては混入の可能性が否定できない場合には、一括表示の枠外で「本品製造工場では〇〇を含む製品を生産しています。」のように注意喚起します。「入っているかもしれません」「入っている場合があります」といった単なる可能性の表示は、枠外であっても認められていません。実際の製造工程や混入の状況を確認せず、定型文だけを表示することは避けます。

## コピーして使える表示のテンプレート

〔 〕の部分を自分の商品に置き換えて使います。書き方の形を示すもので、何を書くかは、規格書と製造工程で確かめてください。

### 原材料名（個別表示）

```text
原材料名：〔原材料〕、〔原材料〕（〔特定原材料等〕を含む）、〔原材料〕／〔添加物〕（〔特定原材料等〕由来）
```

### 原材料名（一括表示）

```text
原材料名：〔原材料〕、〔原材料〕、〔原材料〕／〔添加物〕、（一部に〔特定原材料等〕・〔特定原材料等〕を含む）
```

特定原材料等を2つ以上続けて書くときは、「小麦・卵」のように「・」でつなぎます。

### 一括表示の枠の近くに書く対象範囲

ハンドブックの表示例から、どちらかを選びます。

```text
アレルゲン（29品目対象）
```

```text
アレルゲン（特定原材料のみ）
```

### 一括表示の枠の外に書く注意喚起

```text
本品製造工場では〔特定原材料等の名称〕を含む製品を生産しています。
```

### ネットショップの商品ページ

容器包装と同じ内容を載せ、いつ時点の情報かと、届いた商品の表示も確かめてほしいことを添える例です。

```text
原材料名：〔容器包装の表示と同じ内容〕
アレルゲン（29品目対象）：〔小麦・卵・乳成分〕
※〔2026年11月7日〕時点の情報です。お届けする商品の表示もあわせてご確認ください。
```

### 店頭やメニューで使う一覧表

包装せずに売る商品や、メニューで伝える場合の例です。義務と推奨を分けておくと、2026年4月のような改正のときに見直しやすくなります。

| 商品名 | 特定原材料（義務9品目） | 特定原材料に準ずるもの（推奨20品目） | 確認日 |
|---|---|---|---|
| 〔クッキー〕 | 〔小麦・卵・乳成分〕 | 〔アーモンド〕 | 〔2026年11月7日〕 |
| 〔チーズケーキ〕 | 〔小麦・卵・乳成分〕 | 〔なし〕 | 〔2026年11月7日〕 |

原材料と使う量、含まれるアレルゲンを入れると、一括表示の食品表示ラベルを[食品表示ラベルの作成](/tools/food-label-maker/)で作れます。[チーズケーキ](/tools/food-label-maker/examples/cheesecake/)、[焼き菓子（マドレーヌ）](/tools/food-label-maker/examples/baked-sweets/)、[フルーツサンド](/tools/food-label-maker/examples/fruit-sandwich/)の表示例では、アレルギー表示を含む一括表示の例を確認できます。

## EC商品ページで更新漏れを防ぐ運用

### 商品ページと実物ラベルの食い違いを防ぐ

EC商品ページの情報と、実際に届く商品のラベルが食い違わないようにします。仕入れ先・製造委託先や原材料が変わった場合は、容器包装の表示だけでなく、その原材料を使うすべての商品ページを更新対象に含めます。

例えば、仕入れ先の変更に伴ってソースに小麦が新たに含まれる場合、「ソースを使う商品の洗い出し → 実物ラベルの確認 → 対象商品ページの更新 → 更新漏れの再確認」という手順で進めます。商品説明文へのコピペだけで管理していると、対象商品の洗い出しや更新確認が難しくなります。

消費者庁のガイドブックは、届いた商品の容器包装を確認してもらう注意文を掲載する方法も紹介しています。ただし、注意文を置くことで商品ページの古い情報をそのままにしてよいわけではありません。

### 公開・更新時のチェックリスト

- [ ] 最新の規格書・仕様書で、原材料と添加物を確認したか
- [ ] 義務対象の9品目と推奨20品目を区別して確認したか
- [ ] 古い「28品目」の一覧のまま（カシューナッツが推奨、ピスタチオなし）になっていないか
- [ ] 複合原材料の内訳を名称だけで判断せず確認したか
- [ ] 乳成分、小麦粉などの代替表記・拡大表記を確認したか
- [ ] 原則の個別表示と例外の一括表示を混在させていないか
- [ ] 製造ラインの共有や注意喚起を実際の製造状況に基づいて確認したか
- [ ] 商品ページと実物ラベルの内容に食い違いがないか
- [ ] 原材料変更時に、関連する全商品と更新担当者・確認者を特定したか

商品説明文のコピペ運用からの改善については「[食品表示のコピペ運用が危険な理由と改善策](/articles/food-labeling-copy-paste-risks/)」もご覧ください。

## アレルゲン情報を商品データとして管理する

更新漏れを防ぐには、商品説明文とは別に原材料やアレルゲンをデータとして管理し、商品ページへの反映と更新確認を一つの流れにすることが重要です。

Mix-Juiceが提供するShopifyアプリ「[Fラベル](/service/f-label/)」では、原材料マスターで共通データを使い回し、原材料からアレルゲンを自動判定して表示用データに反映できます。CSVインポートにも対応しているため、既存データを活用して複数商品の食品表示を管理できます。表示内容の最終確認は、実際の原材料・製造工程に基づいて行ってください。

- 書き方は原則として個別表示。一括表示は例外で、欄の最後に「（一部に〇〇・〇〇を含む）」と書き、個別表示との併用はできない
- 卵白・卵黄、乳化剤、複合原材料などは、名称だけで判断せず規格書で確認する
- EC商品ページは実物ラベルとの食い違いを防ぎ、原材料変更時は関連商品を漏れなく更新する

EC全体の食品表示については「[食品をネット販売するときの食品表示 完全ガイド](/articles/food-labeling-complete-guide/)」もあわせてご覧ください。
