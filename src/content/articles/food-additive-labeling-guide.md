容器包装に入れた加工食品を売るときは、使った添加物を表示します。決まりは食品表示基準の第3条にあり、名称の範囲や判断の考え方は、消費者庁の通知「食品表示基準について」と「食品表示基準Q&A」で示されています。

この記事では、お菓子や惣菜を作って売る事業者向けに、添加物の書き方と、表示しなくてよい添加物の判断、「無添加」と書くときの注意を説明し、最後にクッキーの例で添加物の欄を組み立てます。原材料名の欄全体の書き方は「[原材料表示の書き方](/articles/ingredient-labeling-guide/)」で説明しています。

| 決まり | 内容 |
|---|---|
| 書き方 | 添加物の中で重量の割合が高い順に、物質名で書く |
| 用途名の併記 | 甘味料・着色料・保存料など8つの用途で使ったものは「甘味料（スクラロース）」のように用途名も書く |
| 一括名 | 香料・乳化剤・膨張剤など、決められた用途のものはまとめた名称で書ける |
| 書かなくてよいもの | 加工助剤とキャリーオーバー（ただしアレルゲンの表示は必要） |

> 本記事は一般的な情報提供を目的としています。表示例は架空の配合による例示で、個別の商品の表示が適切であることを保証するものではありません。添加物の名称や、加工助剤・キャリーオーバーに当たるかどうかは、添加物の規格書や製造工程を確認し、最新の法令・行政資料に基づいて判断してください。記事の内容は2026年11月3日時点の資料で確認しています。

## 添加物は原材料と区切って書く

添加物は、原材料とは明確に区分して書きます。添加物の欄を別に設けるのが原則で、原材料名の欄に続けて書く場合は「／」などの記号・改行・別の欄で区切ります（Q&A 加工－74・248）。区切りを入れずに続けて書くことはできません。

仕入れた複合原材料（チョコレートやマーガリンなど）に使われている添加物も、複合原材料の括弧の中には書かず、ほかの添加物とまとめて後ろに書きます（Q&A 加工－74）。

## 物質名で書く

添加物は、**添加物の中で重量の割合の高いものから順に、物質名で**書きます（食品表示基準 第3条第1項の表「添加物」の項1）。添加物製剤を使う場合は、目的成分の重量の割合の高い順に書きます（Q&A 加工－91）。

物質名は、食品衛生法施行規則の別表第1などに載っている名称で書くのが原則です。そのほか、通知の別添に載っている範囲で、一般に広く使われている名称（簡略名・類別名）も使えます（通知「食品表示基準について」 加工食品(4)①）。使える名称は添加物ごとに決まっているので、添加物の規格書に書かれた表示名を確認します。

- 増粘安定剤として使う多糖類を2種類以上使うときは、「増粘多糖類」とまとめて書けます（同）。

## 用途名を併記する8つの用途

次の用途で使った添加物は、物質名に加えて**用途名**も書きます（食品表示基準 別表第六）。書き方は「用途名（物質名）」が一般的です。

| 用途名 | 表示の例 |
| --- | --- |
| 甘味料 | 甘味料（スクラロース） |
| 着色料 | 着色料（β－カロテン） |
| 保存料 | 保存料（ソルビン酸カリウム） |
| 増粘剤・安定剤・ゲル化剤（または糊料。主な目的で選ぶ） | 増粘剤（キサンタンガム） |
| 酸化防止剤 | 酸化防止剤（L－アスコルビン酸） |
| 発色剤 | 発色剤（亜硝酸ナトリウム） |
| 漂白剤 | 漂白剤（亜硫酸ナトリウム） |
| 防かび剤（または防ばい剤） | 防かび剤（イマザリル） |

- 1つの添加物が複数の用途に当たる場合は、主な目的の用途名を書けば足ります。用途名が複数ある場合は、そのうちどれかを書きます（通知 加工食品(4)②）。
- 名称に「色」の文字が入る場合（例：カラメル色素）は「着色料」を、「増粘」の文字が入る場合（例：増粘多糖類）は「増粘剤」「糊料」を省略できます（食品表示基準 第3条第1項の表「添加物」の項4）。

主な用途として通知の別添に挙がっていない添加物でも、8つの用途のどれかとして使えば、用途名の併記が必要です（通知 加工食品(4)②）。表の例の名称は物質名で書いたもので、簡略名を使える添加物もあります。

## 一括名で書ける添加物

次の用途で使った添加物は、物質名の代わりに**一括名**で書けます（食品表示基準 第3条第1項の表「添加物」の項3、別表第七）。

| 一括名 | 一括名 | 一括名 |
|---|---|---|
| イーストフード | ガムベース | かんすい |
| 酵素 | 光沢剤 | 香料 |
| 酸味料 | 軟化剤（チューインガム） | 調味料 |
| 豆腐用凝固剤（凝固剤） | 苦味料 | 乳化剤 |
| pH調整剤 | 膨張剤（ベーキングパウダー・ふくらし粉） |  |

- **調味料**は、構成で書き方が変わります。アミノ酸だけなら「調味料（アミノ酸）」、主にアミノ酸でほかの種類も含むなら「調味料（アミノ酸等）」です。核酸・有機酸・無機塩も同じ形です（別表第七）。「等」の部分を具体的に書いても差し支えありません（Q&A 加工－84）。
- 一括名を使える添加物の範囲は、通知の別添で決まっています（通知 加工食品(4)③）。範囲に入らない添加物は物質名で書きます。
- 一括名の後に物質名を書き添えることは任意です。書き添える場合、複数使っているのに「乳化剤（レシチン）」のように1種類だけのように見える書き方はできません（Q&A 加工－78・79）。

## 表示しなくてよい添加物（加工助剤・キャリーオーバー）

### 表示しなくてよいのは2つ

添加物のうち、次の2つは表示が要りません（食品表示基準 第3条第1項の表「添加物」の項1）。

- **加工助剤**：食品の加工の際に加えるもので、完成前に除去されるもの、食品に通常含まれる成分に変わって量を明らかに増やさないもの、食品に残る量が少なく影響を及ぼさないもの
- **キャリーオーバー**：原材料の製造・加工の過程で使われ、その食品の製造では使っておらず、食品の中では効果を発揮できる量より少ない量しか含まれないもの

当たるかどうかは、定義に照らして、使用基準や使い方に即して**個別に判断**します（通知 加工食品(4)③）。

### Q&Aの判断例

消費者庁のQ&Aでは、次のように判断されています。

| 例 | 判断 |
|---|---|
| カステラの製造で使った二酸化炭素（ガス置換） | 食品に残らないため加工助剤。表示不要（加工－86） |
| すし揚げの豆腐に使われた豆腐用凝固剤 | 調味工程を経て最終食品では効果がないためキャリーオーバー。表示不要（加工－87） |
| 甘味料・調味料入りのみそを、煮物に少量使った | 微量でも味に効果があるため、キャリーオーバーに当たらない。表示が必要（加工－92） |

Q&A 加工－92 は、香料や着色料のように五感に訴える添加物も、調味料や甘味料と同じくキャリーオーバーとはみなされず、表示が必要としています。仕入れた原材料に入っている添加物が、自社の製品で効果を発揮しているかどうかを確かめ、当たると説明できる根拠がなければ表示しておくのが安全です。

### 加工助剤・キャリーオーバーでもアレルゲンは書く

加工助剤やキャリーオーバーで添加物の表示が要らない場合でも、その添加物に由来する**特定原材料のアレルギー表示は必要**です（Q&A 加工－74、アレルゲン Q&A B－10）。特定原材料に準ずるもの（20品目）に由来する場合は、可能な限り表示します。

### 栄養強化の目的で使った添加物は、表示が必要になった

以前は、ビタミン・ミネラルなどを栄養強化の目的で使った添加物は、一部の食品を除いて表示が要りませんでした。2025年3月28日の食品表示基準の改正で、この省略の規定が削除され、現在の規定で表示しなくてよいのは加工助剤とキャリーオーバーだけです。

2030年3月31日までに製造・加工・輸入される加工食品は、改正前の規定によることもできます（令和7年3月28日内閣府令第26号 附則第2条）。これから作る表示は、栄養強化の目的の添加物も含めて書いておくと、期限の後に作り直さずに済みます。

## アレルゲンを含む添加物の書き方

特定原材料に由来する添加物は、原材料ごとに書く個別表示では、原則として「物質名（〇〇由来）」と書きます（アレルゲン Q&A E－2・E－3）。

```
乳化剤（大豆由来）、カゼインナトリウム（乳由来）
```

- 一括名で書く添加物は「一括名（〇〇由来）」、用途名を併記する添加物は「用途名（物質名：〇〇由来）」と書きます（E－3）。
- 添加物の場合は「乳成分由来」ではなく「乳由来」と書きます（E－10）。
- 原材料名の欄の最後にまとめる一括表示の場合は、添加物に由来するものも含めて「（一部に〇〇・〇〇を含む）」に書きます。

添加物製剤に含まれる乳糖などの食品素材は、原材料には当たりませんが、それに含まれるアレルゲンは表示が必要です（Q&A 加工－56－1、アレルゲン Q&A E－21）。アレルゲンの表示全体は「[アレルギー表示の対象品目と書き方](/articles/allergen-labeling-guide/)」で説明しています。

## 「無添加」「不使用」と書くとき

消費者庁の「食品添加物の不使用表示に関するガイドライン」（2022年3月）は、「無添加」「不使用」の表示で消費者に誤認を与えないよう注意すべき点を、10の類型にまとめています。不使用表示を一律に禁止するものではなく、食品表示基準の表示禁止事項に当たるかを事業者が自己点検するためのものです。

| 類型 | 内容 |
|---|---|
| 1 | 単なる「無添加」の表示 |
| 2 | 食品表示基準に規定されていない用語を使用した表示（「人工甘味料不使用」など） |
| 3 | 食品添加物の使用が法令で認められていない食品への表示 |
| 4 | 同一機能・類似機能を持つ食品添加物を使用した食品への表示 |
| 5 | 同一機能・類似機能を持つ原材料を使用した食品への表示 |
| 6 | 健康、安全と関連付ける表示 |
| 7 | 健康、安全以外と関連付ける表示 |
| 8 | 食品添加物の使用が予期されていない食品への表示 |
| 9 | 加工助剤、キャリーオーバーとして使用されている（又は使用されていないことが確認できない）食品への表示 |
| 10 | 過度に強調された表示 |

作り手が特に気をつけたいのは類型9です。ガイドラインは、原材料の一部に保存料を使いながら最終製品に「保存料不使用」と書く例を挙げています。Q&Aも、加工助剤やキャリーオーバーで表示が要らない場合でも、添加物を使っているなら使っていない旨は書けないとしています（Q&A 加工－90）。仕入れた原材料の規格書で、添加物が使われていないことを確かめてから書きます。

このほか、添加物を使っていない場合に添加物の欄に「なし」と書くことは認められていません。欄は省略する方が望ましいとされています（Q&A 加工－249・250）。

ガイドラインの対象は容器包装の表示です。ネットショップの商品ページは対象として書かれていませんが、ページの説明文で「無添加」とうたえば、容器包装と同じように誤解を招きます。商品ページでも、ガイドラインの類型に当たらない書き方にしておくことをおすすめします。

## 例：クッキーの添加物の欄を組み立てる

「[原材料表示の書き方](/articles/ingredient-labeling-guide/)」と同じチョコチップクッキーで、添加物の欄を組み立てます。今回は、仕入れたチョコレートの規格書に添加物として「乳化剤（大豆由来）、香料」が書かれているとします。

### 1. 規格書から添加物を書き出す

自社で加えた添加物と、仕入れた原材料に使われている添加物を、すべて書き出します。

| 添加物 | 使い方 | 製品に入る量 |
|---|---|---|
| ベーキングパウダー | 生地に加えた | 3g |
| 乳化剤（大豆由来） | チョコレートに使われている | 0.3g（規格書の配合から計算） |
| 香料 | チョコレートに使われている | 0.1g |

### 2. 表示するかを判断する

この例では、チョコレートはチップの形のまま製品に残り、乳化剤もチョコレートの中で働いていると考えて、表示します。香料は、Q&A 加工－92 の考え方では五感に訴える添加物で、キャリーオーバーにはみなされません。

### 3. 名称を決める

- ベーキングパウダーは、一括名の「膨張剤」で書きます（「ベーキングパウダー」と書くこともできます）。
- 乳化剤と香料も一括名で書きます。
- 8つの用途に当たる添加物はないので、用途名の併記はありません。

### 4. 重量順に並べ、アレルゲンを加える

添加物を製品に入る量の多い順に、「／」の後ろに並べます。アレルゲンは原材料名の欄の最後にまとめる一括表示にし、乳化剤に由来する大豆も含めます。大豆は表示が推奨される品目です。

### 5. できあがり

```
原材料名：小麦粉（国内製造）、バター、砂糖、チョコレート（砂糖、カカオマス、全粉乳、ココアバター）、鶏卵、アーモンドパウダー、食塩／膨張剤、乳化剤、香料、（一部に小麦・卵・乳成分・アーモンド・大豆を含む）
```

チョコレートの乳化剤と香料は、チョコレートの括弧の中ではなく「／」の後ろに書いています。アレルゲンを原材料ごとに書く個別表示にする場合は、添加物は「乳化剤（大豆由来）」のように書き、ほかの原材料にもそれぞれアレルゲンを書きます。個別表示と一括表示を組み合わせることはできません。

同じ配合を[食品表示ラベルの作成ツール](/tools/food-label-maker/)に入れると、この原材料名の欄を含む一括表示と、ネットショップの商品ページに貼るテキストを作れます。ツールは、入力された添加物の名称が正しいかは確かめないため、名称はこの記事と規格書で確認してください。

## よくある質問

**Q. 規格書に書かれた添加物は、すべて自社の製品にも書く必要がありますか？**

原則として書きます。表示しなくてよいのは、加工助剤とキャリーオーバーに当たるものだけで、当たるかどうかは個別に判断します。調味料・甘味料・香料・着色料のように味や見た目に効果があるものは、少量でもキャリーオーバーに当たりません（Q&A 加工－92）。

**Q. ベーキングパウダーは「膨張剤」と「ベーキングパウダー」のどちらで書きますか？**

どちらでも書けます。食品表示基準の別表第七は、膨張剤の一括名として「膨張剤」「膨脹剤」「ベーキングパウダー」「ふくらし粉」を挙げています。

**Q. 添加物を使っていないので「無添加」と書いてもいいですか？**

単なる「無添加」は、何が無添加なのか分からないため、ガイドラインの類型1に当たります。何を使っていないかを具体的に書き、仕入れた原材料にもその添加物が使われていないことを規格書で確かめてください。

**Q. 添加物の名前が正しいか分かりません。**

添加物の規格書に書かれた表示名を確認し、分からなければ添加物メーカーや仕入れ先に問い合わせてください。判断に迷う場合は、地域の保健所などに相談できます。

## まとめ

- 添加物は原材料と「／」などで区切り、添加物の中で重量の割合が高い順に物質名で書く
- 甘味料・着色料・保存料・増粘剤など8つの用途で使ったものは、用途名も書く（「色」「増粘」が名称にあれば省略可）
- 香料・乳化剤・膨張剤・調味料などは一括名で書ける
- 表示しなくてよいのは加工助剤とキャリーオーバーだけ。判断は個別で、アレルゲンの表示は省けない。栄養強化の目的の添加物は2025年の改正で表示が必要になった（2030年3月31日まで経過措置）
- 「無添加」「不使用」は、ガイドラインの10類型に当たらないか確かめる。原材料にキャリーオーバーとして使われていれば「不使用」とは書けない

---

仕入れた原材料が変わると、添加物やアレルゲンの表示も変わります。同じ原材料を使う商品ページをまとめて直すのが大変になってきたら、Mix-Juiceが提供するShopifyアプリ「[Fラベル](/service/f-label/)」もご検討ください。原材料マスターに登録した原材料から、アレルゲンの判定と表示文の作成ができます。表示内容の最終確認は、実際の原材料・製造工程に基づいて行ってください。
