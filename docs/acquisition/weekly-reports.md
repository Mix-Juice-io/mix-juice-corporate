# 週次のアクセスレポート

企業サイト（mix-juice.io）と、Shopify App Store の F-label の掲載のアクセスを、週1回まとめたレポートの一覧。レポートの本体は claude.ai のアーティファクト（既定では作成者だけが開ける）で、ここにはリンクと要点の数字を残す。

- 対象は日曜〜土曜（日本時間）の7日間。Search Console のデータは2〜3日遅れるので、作るのは火曜以降
- レポートには、サイト全体の数字（ユーザー・セッション・デバイス・流入元・入口のページ・キーイベント）、流入した検索語と狙い目の語、改善の提案を載せる
- 数は週単位の件数で、少ないうちは増減を施策の効果と言い切らない。読み方は [README.md](README.md) の「記録のルール」に従う
- 28日ごとの詳しい確認は [reports/](reports/) と時期ごとの Issue（#215・#183・#184）、施策の公開日時は [changelog.md](changelog.md)

## 列の意味

| 列 | 出どころ |
|---|---|
| Google 検索 クリック／表示 | Search Console（ウェブ検索、mix-juice.io） |
| セッション（うち検索） | 企業サイトの GA4 のセッション。「うち検索」は Organic Search（Google・Yahoo!・Bing など） |
| App Store への遷移 | 企業サイトの GA4 の `mix_outbound_shopify_app`（App Store へのボタンのクリック。インストールではない） |
| 掲載ページの訪問 | F-label の掲載ページの GA4 で、App Store の検索・広告・カテゴリーなどから来たセッション（ボットの巡回を除く） |
| インストール（試用）／有料化 | Partner Dashboard のアプリ履歴の件数（自社のストアを除く） |
