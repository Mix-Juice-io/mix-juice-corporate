食品のアレルギー表示（アレルゲン表示）は、**容器包装への表示義務**と、**EC商品ページでの情報提供**を分けて理解することが大切です。この記事では、食品のネット販売を行う事業者向けに、対象品目、個別表示・一括表示の書き方、複合原材料や乳成分の例、更新漏れを防ぐチェックリストを解説します。

まず確認したいポイントは次の4点です。

| 確認したいこと | 結論 |
|---|---|
| 表示義務の対象 | 特定原材料9品目を含む、容器包装された加工食品 |
| 推奨される品目 | 特定原材料に準ずる20品目 |
| 基本的な書き方 | 原則は個別表示。個別表示ができない場合などは一括表示も可能 |
| EC商品ページ | 食品表示基準の直接の適用対象ではないが、実物ラベルとの食い違いを防ぐ情報提供が重要 |

> 本記事は一般的な情報提供を目的としています。表示例は条件を示した例示であり、そのまま使用することで個別の商品の適合性を保証するものではありません。実際の表示は、原材料の規格書や製造工程を確認し、最新の法令・行政資料に基づいて判断してください。

## アレルギー表示の義務とEC商品ページの違い

消費者庁は、特定原材料を含む容器包装された加工食品に、アレルゲンを含む旨の表示を義務付けています。栄養成分表示と違い、事業の規模による省略はありません。作った店で売る場合も、包装して売る商品には表示が必要です。

一方、ECの商品ページへの掲載には食品表示基準が直接適用されません。ただし、消費者庁のEC向けガイドブックは、容器包装の表示事項をできる限り食品表示基準に準じて掲載し、実際に届く商品とのギャップを防ぐよう求めています。購入前に商品を選ぶための重要な情報として、正確で見つけやすい掲載が必要です。

包装せずに対面で売る場合は容器包装への表示義務の対象外ですが、アレルゲンの情報を自主的に伝えることが勧められています。栄養成分表示など、ほかの表示が自社に必要かどうかは、[栄養成分表示の要否チェック](/tools/nutrition-labeling-check/)で確認できます。

## 特定原材料9品目（容器包装への表示義務）

2026年4月にカシューナッツが追加され、対象は9品目になりました。カシューナッツには2028年3月31日までの経過措置がありますが、消費者庁は可能な限り速やかに表示するよう求めています。

| 品目 | 主な食品例 |
|---|---|
| えび | えびせんべい、えびフライなど |
| カシューナッツ | ミックスナッツ、焼き菓子など |
| かに | かにカマボコ、かに缶など |
| くるみ | くるみパン、くるみ菓子など |
| 小麦 | パン、うどん、ソースなど |
| そば | そば麺、そばがきなど |
| 卵 | マヨネーズ、卵焼きなど |
| 乳 | チーズ、バター、ヨーグルトなど |
| 落花生（ピーナッツ） | ピーナッツバター、ピーナッツ菓子など |

※くるみは2023年3月に義務表示へ追加され、2025年3月末で経過措置期間が終了しています。

## 特定原材料に準ずるもの20品目（表示推奨）

以下の20品目は、義務ではありませんが、積極的な表示が推奨されています。

アーモンド、あわび、いか、いくら、オレンジ、キウイフルーツ、牛肉、ごま、さけ、さば、大豆、鶏肉、バナナ、ピスタチオ、豚肉、マカダミアナッツ、もも、やまいも、りんご、ゼラチン

2024年にマカダミアナッツが追加され、まつたけが削除されました。2026年4月にはピスタチオが追加されています。推奨品目を掲載する場合は、義務対象の9品目と区別が付くようにし、最新の対象品目を反映します。

## アレルギー表示の書き方と例

### 個別表示（原則）

個別表示は、原材料名や添加物の物質名の直後に、含まれる特定原材料等を括弧書きで示す方法です。どの原材料に何のアレルゲンが含まれるかを確認しやすくなります。

以下は、小麦粉・卵・バターを使う焼き菓子を想定した例示です。

```text
原材料名：小麦粉（国内製造）、砂糖、卵、バター（乳成分を含む）、食塩
```

### 一括表示（例外）

一括表示は、原材料欄の最後に、食品に含まれるすべての特定原材料等をまとめて示す方法です。個別表示で表示できない場合や、表示可能面積の都合などで個別表示がなじまない場合に認められます。個別表示と一括表示を組み合わせることはできません。

上記と同じ原材料構成を一括表示にした場合の例示は次のとおりです。

```text
原材料名：小麦粉（国内製造）、砂糖、卵、バター、食塩
         （一部に小麦・卵・乳成分を含む）
```

一括表示では、「小麦粉」「全粉乳」などの代替表記・拡大表記で書かれた原材料を含め、すべての特定原材料等を記載します。実際の商品では、ここで示した品目だけを写すのではなく、原材料・添加物と製造工程を確認して表示を作成してください。

### 乳成分は名称だけで判断しない

「乳」については「乳成分を含む」と表示します。例えば、乳を含むチョコレートを原材料に使う場合の個別表示は「チョコレート（乳成分を含む）」です。

バター、チーズなどは拡大表記に該当する場合に含む旨の表示を省略できる場合がありますが、消費者庁のハンドブックは、誤認を防ぐため可能な限り「乳成分を含む」と表示することが望ましいとしています。原材料名に「乳」の文字がないことだけで、表示不要と判断しないようにします。

### 複合原材料は規格書で内訳を確認する

パン粉、しょうゆ、ソース、マーガリンなどの複合原材料には、名称からだけでは分からない特定原材料等が含まれることがあります。仕入れ先の規格書などで内訳を確認し、必要に応じて二次原料・三次原料までさかのぼって確認します。

例えば、使用するマーガリンに乳と大豆が含まれる場合の個別表示は、次のように示せます。

```text
原材料名：小麦粉（国内製造）、砂糖、マーガリン（乳成分・大豆を含む）、食塩
```

同じ「マーガリン」という名称でも内訳が同じとは限りません。商品名だけで例示を転用せず、仕入れ先・製造委託先から入手した最新の情報を使います。

### 製造ラインの共有（コンタミネーション）への対応

意図して使用する原材料の表示と、製造工程での意図しない混入への対応は分けて考えます。製造ラインを共有する場合は、洗浄、製造順の考慮、専用器具の使用などで混入を防ぐことが原則です。

徹底した防止策を講じても、製造ロットによっては混入の可能性が否定できない場合には、一括表示の枠外で注意喚起します。実際の製造工程や混入の状況を確認せず、定型文だけを表示することは避けます。

## EC商品ページで更新漏れを防ぐ運用

### 商品ページと実物ラベルの食い違いを防ぐ

EC商品ページの情報と、実際に届く商品のラベルが食い違わないようにします。仕入れ先・製造委託先や原材料が変わった場合は、容器包装の表示だけでなく、その原材料を使うすべての商品ページを更新対象に含めます。

例えば、仕入れ先の変更に伴ってソースに小麦が新たに含まれる場合、「ソースを使う商品の洗い出し → 実物ラベルの確認 → 対象商品ページの更新 → 更新漏れの再確認」という手順で進めます。商品説明文へのコピペだけで管理していると、対象商品の洗い出しや更新確認が難しくなります。

消費者庁のガイドブックは、届いた商品の容器包装を確認してもらう注意文を掲載する方法も紹介しています。ただし、注意文を置くことで商品ページの古い情報をそのままにしてよいわけではありません。

### 公開・更新時のチェックリスト

- [ ] 最新の規格書・仕様書で、原材料と添加物を確認したか
- [ ] 義務対象の9品目と推奨20品目を区別して確認したか
- [ ] 複合原材料の内訳を名称だけで判断せず確認したか
- [ ] 乳成分、小麦粉などの代替表記・拡大表記を確認したか
- [ ] 原則の個別表示と例外の一括表示を混在させていないか
- [ ] 製造ラインの共有や注意喚起を実際の製造状況に基づいて確認したか
- [ ] 商品ページと実物ラベルの内容に食い違いがないか
- [ ] 原材料変更時に、関連する全商品と更新担当者・確認者を特定したか

商品説明文のコピペ運用からの改善については「[食品表示のコピペ運用が危険な理由と改善策](/articles/food-labeling-copy-paste-risks/)」もご覧ください。

## アレルゲン情報を商品データとして管理する

更新漏れを防ぐには、商品説明文とは別に原材料やアレルゲンをデータとして管理し、商品ページへの反映と更新確認を一つの流れにすることが重要です。

Mix-Juiceが提供するShopifyアプリ「[Fラベル](/service/f-label/)」では、原材料マスターで共通データを使い回し、原材料からアレルゲンを自動判定して表示用データに反映できます。CSVインポートにも対応しているため、既存データを活用して複数商品の食品表示を管理できます。表示内容の最終確認は、実際の原材料・製造工程に基づいて行ってください。

## まとめ

- 特定原材料9品目は容器包装された加工食品の**表示義務の対象**（カシューナッツには2028年3月31日までの経過措置あり）
- 推奨20品目は義務ではないが、積極的な表示が推奨される
- 書き方は原則として個別表示。一括表示は例外で、個別表示との併用はできない
- 複合原材料や乳成分は名称だけで判断せず、規格書などで確認する
- EC商品ページは実物ラベルとの食い違いを防ぎ、原材料変更時は関連商品を漏れなく更新する

EC全体の食品表示については「[食品をネット販売するときの食品表示 完全ガイド](/articles/food-labeling-complete-guide/)」もあわせてご覧ください。
