容器包装に入れた加工食品を売るときは、使った原材料を「原材料名」の欄に書きます。決まりは食品表示基準の第3条にあり、細かい扱いは消費者庁の「食品表示基準Q&A」で示されています。

この記事では、お菓子や惣菜を作って売る事業者向けに、原材料名の欄の書き方を、順番・複合原材料・添加物との区切り・どこまで書くかの順に説明し、最後にクッキーの配合例で組み立てます。

| 決まり | 内容 |
|---|---|
| 順番 | 原材料に占める重量の割合が高いものから順に書く（製造時の配合で決める） |
| 名称 | その原材料の最も一般的な名称で書く |
| 複合原材料 | 名称の次の括弧に、内訳を重量順で書く。条件を満たせば「その他」や省略ができる |
| 添加物 | 原材料と明確に区切る（「／」・改行・別の欄） |

> 本記事は一般的な情報提供を目的としています。表示例は架空の配合による例示で、個別の商品の表示が適切であることを保証するものではありません。実際の表示は、原材料の規格書や製造工程を確認し、最新の法令・行政資料に基づいて判断してください。記事の内容は2026年11月3日時点の資料で確認しています。

## 原材料名の表示が必要な食品

食品表示基準の第3条は、容器包装に入れた加工食品（一般用加工食品）を販売するときの表示を定めています。原材料名はその表示事項の一つで、ネットショップで売る商品も、包装して店頭で売る商品も対象です。

一方、第5条により、**食品を作った場所で販売する場合**は、原材料名の表示は要りません（特定保健用食品・機能性表示食品を除く）。洋菓子店が店内の厨房で作った焼き菓子を、その店で包装して売る場合などです。ただし同じ表の中で省略できるとされていない事項（アレルゲン・期限・保存方法など）は省けません。同じ商品をネットショップや別の店舗で売る分は、作った場所での販売ではないため、原材料名の表示が必要です。

このほか、次の場合も原材料名を省略できます（第3条第3項）。

- 容器包装の表示可能面積がおおむね30cm²以下のもの（特定保健用食品・機能性表示食品を除く）
- 原材料が1種類だけのもの（缶詰・食肉製品や、遺伝子組換えの表示をする場合などを除く）

原材料が1種類でも、「きなこ」「上新粉」のように名称から原材料が分かりにくいものは、「大豆」「うるち米」と書くことが望ましいとされています（Q&A 加工－162）。

自社の商品でほかの表示事項がどこまで必要かは、[栄養成分表示の要否チェック](/tools/nutrition-labeling-check/)や、[食品表示の完全ガイド](/articles/food-labeling-complete-guide/)で確認できます。

## 基本の書き方

### 重量の割合が高い順に書く

原材料は、**原材料に占める重量の割合の高いものから順に**書きます（第3条第1項の表「原材料名」の項1の一）。順番は、基本的に**製造時の配合割合**で決めます（Q&A 加工－57－1）。

ただし、配合した量と製品に残る量が明らかに違う場合は、誤認を与えないよう注意が必要です。

- **揚げ油・漬け込んで捨てる調味液など**：製品に吸収される量を、自社や業界の試験結果などから推測し、製品に含まれる重量の順で書きます。
- **濃縮原料・乾燥原料**：製造の際に戻して使うものは、還元した状態や乾燥前の状態に換算した重量の順で書くことができます。

配合を変えたら、変更後の配合で順番を見直します（Q&A 加工－72）。季節によって配合を変える商品は、変えるたびに表示を確認します。

### 最も一般的な名称で書く

原材料は、その**最も一般的な名称**で書きます。商品名や社内の呼び名ではなく、消費者が読んで分かる名称にします。

- 「黒糖」は「砂糖」と書けますが、糖アルコールの「還元水あめ」は砂糖ではないので「還元水あめ」と書きます（Q&A 加工－61）。
- 使っていない原材料の名前を書いたり、使った原材料を書かなかったりするのは、食品表示基準に反します（Q&A 加工－70）。

食品表示基準は、いくつかの原材料に使える名称も定めています（第3条第1項の表「原材料名」の項3）。例えば、食用油脂は「植物油脂」「動物油脂」などと書けます。香辛料は、原材料に占める重量の割合が2%以下なら「香辛料」とまとめて書けます（Q&A 加工－64）。

### 添加物は原材料と区切る

添加物は、原材料とは**明確に区分して**書きます。添加物の欄を別に設けるのが原則で、原材料名の欄に続けて書く場合は、次のいずれかで区切ります（Q&A 加工－74・248）。

1. 記号で区切る（例：「食塩／膨張剤」）
2. 改行して書く
3. 別の欄に書く

**区切りを入れずに続けて書くことはできません**（Q&A 加工－248）。順序は、原材料、添加物の順が一般的で、その順が望ましいとされています（Q&A 加工－73）。添加物も、添加物の中で重量の割合の高い順に書きます。

## 複合原材料の書き方

### 複合原材料とは

2種類以上の原材料からできた原材料を**複合原材料**といいます。仕入れたチョコレート、マーガリン、ビスケット、マヨネーズなどが当たります。小麦粉のように1種類の原材料からできた加工品は、複合原材料ではありません。

### 名称の次の括弧に、内訳を重量順で書く

複合原材料は、**名称の次に括弧を付けて、その内訳を、複合原材料の中で重量の割合が高い順に**書きます（第3条第1項の表「原材料名」の項1の二のイ）。内訳は、仕入れ先の規格書で確認します。

```
原材料名：小麦粉、マーガリン（食用植物油脂、食用精製加工油脂、脱脂粉乳、食塩）、砂糖、…
```

複合原材料そのものの位置は、製品の原材料の中での重量の順で決めます。内訳は括弧の中にまとめ、ほかの原材料とは混ぜません（内訳をほかの原材料と並べて書ける場合は後で説明します）。

### 「その他」にまとめられる原材料

内訳が3種類以上あるときは、**複合原材料の中で重量の順が3位以下で、かつ割合が5%未満**の原材料を「その他」と書けます（同イのただし書）。

消費者庁のQ&Aの例では、マヨネーズの内訳のうち、5%未満の香辛料・食塩・砂糖を「その他」にしています。3位の醸造酢は5%以上使っているため、「その他」にはできません（Q&A 加工－51）。

```
マヨネーズ（食用植物油脂、卵黄（卵を含む）、醸造酢、その他）
```

「その他」にした原材料より後ろの原材料だけを抜き出して書くことはできません。後ろの原材料を書きたいときは、その前の原材料も「その他」にせず、すべて重量順に書きます（Q&A 加工－54）。

### 内訳を省略できる場合

次のどちらかに当たる場合は、複合原材料の内訳を省略できます（同ロ）。

- **複合原材料が、製品の原材料に占める重量の割合で5%未満**
- **複合原材料の名称から、その原材料が明らかなもの**（Q&A の例ではマヨネーズ）

内訳を省略した場合も、複合原材料に含まれるアレルゲンの表示は必要です。上の例のマヨネーズなら、「マヨネーズ（卵を含む）」のように書きます（Q&A 加工－51）。

### 元の原材料に分けて書ける場合と、書けない場合

単に混ぜただけなど、原材料の性状に大きな変化がない複合原材料は、その内訳をほかの原材料と並べて、全体の重量順で書くこともできます（同項1の三）。Q&Aでは、消費者が名称から内容を理解できない場合や、単に混ぜただけで、複合原材料として示すメリットが少ない場合に、総合的に判断するとしています（Q&A 加工－52）。

一方、一般的な名称がある複合原材料や、性状が大きく変わったものは、元の原材料に分けて書くことはできません（Q&A 加工－53）。例えばどら焼きの「皮」「つぶあん」を、卵・小麦粉・小豆などに全部ばらして並べることはできません。

### 複合原材料に含まれる添加物

複合原材料に使われている添加物は、**括弧の中には書きません**。その食品に使ったほかの添加物とまとめて、「／」などで区切った後ろに書きます（Q&A 加工－74）。

## どこまで書くか

### 少量の原材料も書く

原材料として使ったものは、**どんなに少量でも表示が必要**です（Q&A 加工－56－1）。仕上げに少しだけ使うナッツや洋酒も書きます。

柏もちの「柏の葉」のように、ふつう食べないものは原材料に当たりません。添加物の製剤に含まれる食品素材（賦形剤）も原材料に当たりませんが、乳糖のようにアレルゲンを含むものは、アレルギーの表示が必要です（同）。

### 加工助剤・キャリーオーバーは書かなくてよい

添加物のうち、**加工助剤**（完成前に除去されるものなど）と**キャリーオーバー**（原材料の製造で使われ、製品では効果を発揮しない量しか残らないもの）は、表示が要りません（第3条第1項の表「添加物」の項1）。ただし、それらに由来する特定原材料のアレルギー表示は必要です（Q&A 加工－74）。

どの添加物が当たるかは、原材料の規格書と製造工程から判断します。迷うものは、仕入れ先や保健所に確認してください。

### 水は書かないことが多い

原材料としての水を書くかどうかを直接定めた規定は、食品表示基準とQ&Aに見当たりません。消費者庁のQ&Aでは、水は「慣例として表示していない場合が多い」とされています（Q&A 原原－5）。

水を書く場合は、ほかの原材料と同じく重量順の位置に書きます。水を最初に書いても、原料原産地表示の対象は水ではなく、水以外で重量1位の原材料です（同）。

### 同じ種類の原材料はまとめて書ける

同じ種類の原材料を何種類も使うときは、「野菜」「食肉」「魚介類」「糖類」などの名称の次に括弧を付けて、まとめて書けます（第3条第1項の表「原材料名」の項2の一、Q&A 加工－58）。

```
原材料名：野菜（トマト、たまねぎ、にんじん、にんにく、セロリ、パセリ）、トマトペースト、砂糖、植物油脂、食塩、でん粉、香辛料
```

この例で「野菜」にまとめられるのは、生や冷凍の野菜として使ったものだけです。トマトペーストは「野菜」に含めません。野菜の一部だけを抜き出したり、一部を「その他」にしたりすることもできません（Q&A 加工－58）。

即席めんの「めん」「スープ」「かやく」のように、構成要素ごとに分けて書くこともできます（同項2の二）。

## 例：クッキーの原材料名の欄を組み立てる

架空の洋菓子店が、自分の店で焼いたチョコチップクッキーを袋に入れ、ネットショップで売る場合で組み立てます。

### 1. 使った原材料と添加物を書き出す

配合表から、原材料と添加物を分けて書き出します。仕入れたチョコレートは、規格書で内訳と添加物を確認します。

| 原材料 | 配合量 | 区分 |
|---|---|---|
| 小麦粉 | 200g | 原材料 |
| バター | 120g | 原材料 |
| 砂糖 | 90g | 原材料 |
| チョコレート | 60g | 複合原材料 |
| 鶏卵 | 50g | 原材料 |
| アーモンドパウダー | 20g | 原材料 |
| 水 | 10g | 原材料 |
| 食塩 | 2g | 原材料 |
| 膨張剤 | 3g | 添加物 |

小麦粉は国内の製粉会社から仕入れたものです。チョコレートの規格書には、内訳が「砂糖45%、カカオマス35%、植物油脂11%、ココアバター5%、全粉乳4%」、添加物が「香料」と書かれているとします。

### 2. 重量順に並べる

原材料を配合量の多い順に並べます。チョコレートは配合全体（555g）の約11%で、5%以上あるため、内訳を括弧で書きます。

チョコレートの内訳のうち、全粉乳（4%）は3位以下で5%未満なので「その他」にもできます。ココアバターはちょうど5%で、「5%未満」に当たらないため「その他」にはできません。この例では内訳をすべて書きます。

水は、慣例に従って書かないことにします。

### 3. 添加物を区切って後ろに書く

膨張剤と、チョコレートに使われている香料を、「／」の後ろに重量順で書きます。香料はチョコレートの括弧の中には書きません。

### 4. アレルゲンと原料原産地を加える

- **アレルゲン**：小麦（小麦粉）・卵（鶏卵）・乳成分（バター・全粉乳）が特定原材料、アーモンドは表示が推奨される品目です。ここでは原材料名の欄の最後にまとめて書く一括表示にしています。個別表示との違いは「[アレルゲン表示の義務と通販での対応方法](/articles/allergen-labeling-guide/)」で説明しています。
- **原料原産地**：重量1位の原材料（小麦粉）の産地を書きます。小麦粉は国内で製粉された加工食品なので「国内製造」と書きます。どの原材料にどう書くかは、[原料原産地表示のチェック](/tools/origin-labeling-check/)で確認できます。

### 5. できあがり

```
原材料名：小麦粉（国内製造）、バター、砂糖、チョコレート（砂糖、カカオマス、植物油脂、ココアバター、全粉乳）、鶏卵、アーモンドパウダー、食塩／膨張剤、香料、（一部に小麦・卵・乳成分・アーモンドを含む）
```

水を書く場合は、アーモンドパウダー（20g）と食塩（2g）の間に「水」が入ります。

同じ配合を[食品表示ラベルの作成ツール](/tools/food-label-maker/)に入れると、この原材料名の欄に、名称・期限・保存方法などを加えた一括表示と、ネットショップの商品ページに貼るテキストを作れます。マーガリン（複合原材料）や複数の添加物を使う例は、「[焼き菓子（マドレーヌ）の表示例](/tools/food-label-maker/examples/baked-sweets/)」で見られます。

## よくある質問

**Q. 原材料の順番は、焼いた後の重さで決めますか？**

基本は製造時の配合割合で決めます。揚げ油や、漬け込んで捨てる調味液のように、配合した量と製品に残る量が明らかに違うものは、製品に残る量を推測して順番を決めます（Q&A 加工－57－1）。

**Q. 仕入れた原材料に何が入っているか分かりません。**

仕入れ先から規格書（原材料・添加物・アレルゲンの内訳）を取り寄せてください。複合原材料の内訳や、アレルゲン・添加物の確認に必要です。規格書が改訂されたら、表示も見直します。

**Q. 弁当などで原材料が多く、欄に収まりません。**

一括表示の枠の中に表示している場所を書けば、原材料名を別の場所に表示することもできます（Q&A 加工－247）。

**Q. ネットショップの商品ページにも原材料を書く必要がありますか？**

商品ページへの掲載には食品表示基準が直接は適用されません。消費者庁のガイドブックは、購入前に確認できるよう、容器包装と同じ表示事項をできるだけ提供することが望ましいとしています。詳しくは「[食品表示の完全ガイド](/articles/food-labeling-complete-guide/)」で説明しています。

## まとめ

- 原材料名は、容器包装に入れた加工食品に必要。作った場所で売る場合は不要
- 原材料は、製造時の配合で重量の割合が高い順に、最も一般的な名称で書く
- 複合原材料は、名称の次の括弧に内訳を重量順で書く。3位以下で5%未満の内訳は「その他」にでき、製品の5%未満か名称から明らかなものは内訳を省略できる
- 添加物は「／」・改行・別の欄で原材料と区切り、複合原材料に含まれる添加物もまとめて後ろに書く
- 少量の原材料も書く。加工助剤・キャリーオーバーは書かなくてよいが、アレルゲンの表示は必要。水は慣例として書かないことが多い

---

原材料が変わると、原材料名だけでなくアレルゲンや原料原産地の表示も変わります。商品が増えて、同じ原材料を使う商品ページをまとめて直すのが大変になってきたら、Mix-Juiceが提供するShopifyアプリ「[Fラベル](/service/f-label/)」もご検討ください。原材料マスターに登録した原材料から、アレルゲンの判定と表示文の作成ができます。表示内容の最終確認は、実際の原材料・製造工程に基づいて行ってください。
